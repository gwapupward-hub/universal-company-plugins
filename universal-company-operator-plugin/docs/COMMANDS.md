# Command Console

## Single-Operator Commands

| Command | Operator | Use Case |
|---|---|---|
| `/run business` | Master router | General business request, synthesis, routing |
| `/run ceo` | CEO strategy | Vision, positioning, priorities, tradeoffs |
| `/run product` | Product/engineering | PRDs, roadmaps, specs, implementation planning |
| `/run growth` | Growth/marketing | Campaigns, content, funnels, acquisition |
| `/run sales` | Sales/partnerships | Outreach, pipeline, partnership strategy |
| `/run ops` | Operations | SOPs, hiring, delivery, internal systems |
| `/run finance` | Finance | Pricing, unit economics, runway, budgets |
| `/run success` | Customer success | Onboarding, retention, support, feedback |
| `/run data` | Data/analytics | KPIs, dashboards, experiments, reporting |
| `/run design` | Design/UX | User journeys, conversion UX, brand systems |
| `/run legal` | Legal/compliance | Issue spotting, risk checklist, escalation points |
| `/run community` | Community | Engagement, moderation, audience building |

## Multi-Operator Commands

| Command | Operators |
|---|---|
| `/run launch` | business, product, growth, sales, success |
| `/run revenue` | ceo, finance, sales, growth |
| `/run audit` | business, ceo, ops, finance, data |
| `/run roadmap` | ceo, product, growth, ops |

## Standard Output

Every command should return:

1. Command interpreted
2. Operators activated
3. Assumptions
4. Diagnosis
5. Action plan
6. Approval-gated actions
7. Next step
