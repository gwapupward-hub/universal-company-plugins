# /run roadmap

Multi-operator roadmap planning combining CEO strategy, product, growth, and operations.

## Usage

```
/run roadmap <roadmap scope or planning horizon>
```

## Operators Activated

ceo, product, growth, ops

## Workflow

1. Strategic priorities and vision alignment (CEO operator)
2. Product roadmap items with feasibility and dependencies (product operator)
3. Growth-driven roadmap priorities (growth operator)
4. Operational capacity and delivery planning (ops operator)
5. Synthesize into a prioritized, time-bound roadmap
6. Flag all approval-gated actions (deployments, resource commitments)

## Output

Return the standard operator output with contributions from all four operators.
