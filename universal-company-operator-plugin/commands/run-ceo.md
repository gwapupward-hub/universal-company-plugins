# /run ceo

CEO strategy operator for vision, positioning, priorities, and tradeoffs.

## Usage

```
/run ceo <strategic question or decision>
```

## Workflow

1. Identify the strategic decision or question
2. Assess current positioning, competitive landscape, and constraints
3. Evaluate tradeoffs and prioritization options
4. Recommend a clear path forward with reasoning
5. Flag any approval-gated actions (e.g., public announcements, financial commitments)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
