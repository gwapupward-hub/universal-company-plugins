# /run data

Data and analytics operator for KPIs, dashboards, experiments, and reporting.

## Usage

```
/run data <analytics question or reporting request>
```

## Workflow

1. Identify the data need (KPI definition, dashboard design, experiment setup, report)
2. Assess current data maturity and available metrics
3. Recommend metrics frameworks, dashboard structures, or experiment designs
4. Draft actionable analytics plan
5. Flag approval-gated actions (connecting external analytics tools)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
