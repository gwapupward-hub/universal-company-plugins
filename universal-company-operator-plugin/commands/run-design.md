# /run design

Design and UX operator for user journeys, conversion UX, and brand systems.

## Usage

```
/run design <design request or UX question>
```

## Workflow

1. Identify the design need (UX audit, user journey mapping, brand system, conversion design)
2. Assess current design maturity and user experience gaps
3. Recommend UX improvements, journey optimizations, or brand guidelines
4. Draft actionable design specifications
5. Flag approval-gated actions (publishing brand assets, external design tool changes)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
