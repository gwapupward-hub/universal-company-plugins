# /run

Universal Company Operator command router.

## Usage

```txt
/run <command> <goal/context>
```

Examples:

```txt
/run audit my agency's client onboarding system
/run revenue create a monetization strategy for a newsletter
/run launch new SaaS beta for small businesses
/run product turn this idea into a PRD
```

## Supported Commands

business, ceo, product, growth, sales, ops, finance, success, data, design, legal, community, launch, revenue, audit, roadmap.

## Execution Rules

- classify the command,
- activate matching operators,
- state assumptions,
- produce concrete output,
- list approval-gated actions separately.
