# /run audit

Multi-operator business and system audit combining business, CEO, ops, finance, and data.

## Usage

```
/run audit <what to audit>
```

## Operators Activated

business, ceo, ops, finance, data

## Workflow

1. Business health assessment (business operator)
2. Strategic alignment review (CEO operator)
3. Operations efficiency audit (ops operator)
4. Financial health check (finance operator)
5. Data and metrics review (data operator)
6. Synthesize findings into a prioritized audit report
7. Flag all approval-gated remediation actions

## Output

Return the standard operator output with contributions from all five operators.
