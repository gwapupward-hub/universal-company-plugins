# /run ops

Operations and COO operator for SOPs, hiring, delivery, and internal systems.

## Usage

```
/run ops <operations request>
```

## Workflow

1. Identify the operational need (process, hiring, delivery, tooling, systems)
2. Assess current operations maturity and bottlenecks
3. Recommend SOPs, workflows, or system improvements
4. Draft implementation plan with clear ownership
5. Flag approval-gated actions (hiring, tool purchases, system changes)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
