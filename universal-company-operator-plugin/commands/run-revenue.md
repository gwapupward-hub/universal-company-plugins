# /run revenue

Multi-operator monetization planning combining CEO strategy, finance, sales, and growth.

## Usage

```
/run revenue <monetization goal or revenue question>
```

## Operators Activated

ceo, finance, sales, growth

## Workflow

1. Strategic positioning for revenue (CEO operator)
2. Pricing model and unit economics analysis (finance operator)
3. Sales pipeline and conversion strategy (sales operator)
4. Growth channels for revenue scaling (growth operator)
5. Synthesize a unified monetization plan
6. Flag all approval-gated actions across operators

## Output

Return the standard operator output with contributions from all four operators.
