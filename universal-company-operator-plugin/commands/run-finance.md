# /run finance

Finance and monetization operator for pricing, unit economics, runway, and budgets.

## Usage

```
/run finance <finance question or pricing request>
```

## Workflow

1. Identify the financial need (pricing, margins, runway, budget, revenue model)
2. Assess current financial position and constraints
3. Model pricing options or budget scenarios
4. Recommend actionable financial decisions
5. Flag approval-gated actions (payment collection, financial filings, money movement)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
