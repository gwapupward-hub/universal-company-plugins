# /run business

Route and synthesize any general business request across all operator domains.

## Usage

```
/run business <goal or question>
```

## Workflow

1. Classify the business request into one or more operator domains
2. Activate the matching operators (strategy, product, growth, sales, ops, finance, success, data, design, legal, community)
3. Gather universal context (company, stage, customer, offer, model, bottleneck, resources)
4. Synthesize recommendations across activated operators
5. Produce actionable output with approval-gated actions separated

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
