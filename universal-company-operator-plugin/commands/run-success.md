# /run success

Customer success and support operator for onboarding, retention, support, and feedback loops.

## Usage

```
/run success <customer success question>
```

## Workflow

1. Identify the customer success need (onboarding, retention, support, feedback)
2. Assess current customer journey and pain points
3. Recommend process improvements or support strategies
4. Draft onboarding flows, support templates, or feedback systems
5. Flag approval-gated actions (external messaging, ticket creation)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
