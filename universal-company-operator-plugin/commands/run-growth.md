# /run growth

Growth and marketing operator for campaigns, content, funnels, and acquisition strategy.

## Usage

```
/run growth <growth goal or channel question>
```

## Workflow

1. Identify the growth objective (acquisition, activation, retention, referral, revenue)
2. Assess current channels, funnel metrics, and constraints
3. Recommend campaigns, content strategies, or funnel optimizations
4. Draft actionable growth experiments with success metrics
5. Flag approval-gated actions (publishing, ad spend, external messaging)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
