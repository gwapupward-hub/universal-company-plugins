# /run launch

Multi-operator launch coordination combining business, product, growth, sales, and success.

## Usage

```
/run launch <launch goal or product to launch>
```

## Operators Activated

business, product, growth, sales, success

## Workflow

1. Define launch scope, timeline, and success criteria
2. Product readiness assessment (features, quality, documentation)
3. Growth and marketing launch plan (channels, messaging, timing)
4. Sales enablement preparation (materials, pricing, pipeline)
5. Customer success readiness (onboarding, support, feedback loops)
6. Synthesize a unified go-to-market execution plan
7. Flag all approval-gated actions across operators

## Output

Return the standard operator output with contributions from all five operators.
