# /run sales

Sales and partnerships operator for outreach, pipeline, and partnership strategy.

## Usage

```
/run sales <sales goal or partnership question>
```

## Workflow

1. Identify the sales objective (pipeline, outreach, closing, partnerships)
2. Assess current pipeline, ICP, and conversion rates
3. Recommend outreach strategies, messaging, or partnership structures
4. Draft actionable next steps with clear owners
5. Flag approval-gated actions (external messaging, contract changes)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
