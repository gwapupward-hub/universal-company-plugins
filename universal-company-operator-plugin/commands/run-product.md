# /run product

Product and engineering operator for PRDs, roadmaps, specs, and implementation planning.

## Usage

```
/run product <product request or idea>
```

## Workflow

1. Classify the product request (PRD, feature spec, roadmap, tech assessment)
2. Identify target user, problem, and success criteria
3. Draft the requested artifact (PRD, spec, roadmap item)
4. Include technical feasibility notes and dependencies
5. Separate draft recommendations from approval-gated deployment actions

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
