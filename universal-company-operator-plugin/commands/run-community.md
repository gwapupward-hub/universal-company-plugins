# /run community

Community and audience operator for engagement, moderation, and audience building.

## Usage

```
/run community <community question or strategy request>
```

## Workflow

1. Identify the community need (engagement, moderation, growth, content, events)
2. Assess current community health and engagement metrics
3. Recommend strategies for building and nurturing the community
4. Draft engagement plans, moderation guidelines, or content calendars
5. Flag approval-gated actions (public posting, external messaging)

## Output

Return the standard operator output: command interpreted, operators activated, assumptions, diagnosis, action plan, approval-gated actions, next step.
